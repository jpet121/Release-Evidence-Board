Reproduce the status offline

  1. For each behavior, use its approved test IDs and planned attempts as the roster. Each planned slot counts once. A run is incomplete if any slot is missing or has ERROR, SKIPPED or UNKNOWN. RUN_ONLY leaves every slot missing.
  2. Each run can reach at most planned slots minus FAIL slots. A failed must-pass slot or a maximum possible score below the pass mark makes that run definitive. Compare the maximum possible count times 10,000 with the threshold in basis points times the planned count.
  3. Choose the latest producer run finish. Among equal instants select an incomplete run if present, then use the higher ledger sequence among equally complete runs.
  4. Any definitive failure for this behavior yields FAIL. Otherwise a missing or incomplete current run yields UNKNOWN. A complete current run is STALE only after its oldest result plus the allowed hours. Otherwise it is PASS. Use the recorded assessment time.
  5. Every required behavior must be PASS for SUFFICIENT. Optional behaviors retain their own statuses outside the required denominator.
